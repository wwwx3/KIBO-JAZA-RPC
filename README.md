## ✨ Overview

The **Kibo-RPC** is an international challenge hosted by **JAXA, NASA, ESA, CSA** where students control the **Astrobee robot** inside the ISS (´▽\`ʃ♡ƪ)

This repo is my space to:

* 🛠️ Practice and test different modules
* 📚 Save utils + notes so I don’t lose them
* 🎯 Track my progress for the **6th Kibo (JAZA) RPC**

## 🧑‍💻 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/<your-username>/KIBO-JAZA-RPC.git
cd KIBO-JAZA-RPC
```

### 2. Install requirements

```bash
pip install -r requirements.txt
```

### 3. Run a module

```bash
python modules/<your_module>.py
```
